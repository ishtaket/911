# Legal Boundaries

Allowed:
- public web pages
- official APIs
- public social posts/pages/groups
- public archives
- public indexed snippets
- user-provided media
- permissioned sources

Forbidden:
- hacking
- credential theft
- leaked/stolen datasets
- private profiles
- bypassing login
- bypassing privacy settings
- rate-limit evasion
- fake identity deception
- automated contact without operator approval

Sensitive data:
- location
- face images
- contact details
- minors
- health/biometric-like data

Rule:
No output can claim a person was found without human confirmation.
