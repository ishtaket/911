## 1. Профили

### 1.1 Создание профиля
1. Открыть приложение — экран **Profiles** (пустой список)
2. Нажать **+** (фиолетовая кнопка внизу справа)
3. Заполнить поля:
   - **Full name** — обязательное поле (например: Мария Иванова)
   - **Age** — число (74)
   - **Condition / Diagnosis** — текст (Alzheimer's disease)
   - **Distinguishing features** — текст (Седые волосы, синее пальто)
   - **Habits** — текст (Гуляет по утрам в парке)
   - **Known locations** — текст (Центральный парк, Почта)
   - **Aliases** — через запятую (Маша, Мария Петровна)
4. Нажать **галочку** (кнопка сохранения)
5. **Ожидание:** возврат на список профилей, профиль появился в списке

### 1.2 Просмотр профиля
1. Нажать на профиль в списке
2. **Ожидание:** экран **Person Profile** с секциями:
   - Basic Info (имя, возраст, диагноз, приметы)
   - Historical Places (пустой, кнопка "Add place")
   - Кнопка **MISSING** внизу (красная)

### 1.3 Редактирование профиля
1. На экране профиля нажать **карандаш** (вверху справа)
2. Изменить любое поле
3. Нажать **галочку**
4. **Ожидание:** возврат на профиль, данные обновились

### 1.4 Добавление исторического места
1. На экране профиля нажать **+ Add place**
2. Заполнить:
   - Title (Дом)
   - Latitude (55.7558)
   - Longitude (37.6173)
   - Source (Семья)
3. Сохранить
4. **Ожидание:** место появилось в списке Historical Places

## 2. Пропавший (Missing Case)

### 2.1 Запуск дела
1. На экране профиля нажать **MISSING**
2. Экран **Report Missing** — заполнить:
   - **Location name** — где видели последний раз (Центральный парк)
   - **Latitude** — координата (55.7558)
   - **Longitude** — координата (37.6173)
   - **Clothing** — описание одежды (Синее зимнее пальто, серый шарф)
   - **Notes** — заметки (Ушла из дома в 8 утра)
3. Нажать **START SEARCH CASE**
4. **Ожидание:** переход на экран **Active Case Dashboard**

### 2.2 Панель управления делом
На экране Active Case проверить:
- Карточка с именем, возрастом, диагнозом, приметами
- Секция **Case Info**: дата, время, место, координаты, одежда
- Секция **Actions** — 7 кнопок:
  1. Search Map
  2. Search Leads
  3. Witness Reports
  4. Outreach
  5. Web Search
  6. Social Search
  7. Audit Log

---

## 3. Карта поиска (Search Map)

### 3.1 Открытие карты
1. На панели дела нажать **Search Map**
2. **Ожидание:** карта Google Maps с:
   - Маркер последнего места (красный)
   - Круги зон поиска (фиолетовые — предложенные)
   - Легенда вверху: Zones, Suggested, Leads, Reports

### 3.2 Тепловая карта (Heat Map)
1. Если есть данные (лиды, отчёты) — появится кнопка **Layers** (FAB внизу)
2. Нажать FAB — включается тепловая карта
3. Нажать ещё раз — выключается
4. **Ожидание:** иконка меняется (Layers ↔ LayersClear)

> **Примечание:** Google Maps требует API-ключ. Без ключа карта будет серой. Зоны и маркеры всё равно отрисовываются.

---

## 4. Поисковые зацепки (Search Leads)

### 4.1 Просмотр лидов
1. На панели дела нажать **Search Leads**
2. **Ожидание:** список лидов (пустой для нового дела)

### 4.2 Добавление лида вручную
1. Нажать **+**
2. Заполнить:
   - Type — выбрать (MANUAL, WEB, SOCIAL, MESSENGER, WITNESS)
   - Matched value — что нашли (Похожий человек у метро)
   - Location name — место
   - Latitude / Longitude — координаты
   - Confidence — ползунок 0-1
3. Сохранить
4. **Ожидание:** лид появился в списке со статусом NEW

### 4.3 Управление лидом
1. Нажать на лид
2. Доступные действия:
   - **Confirm** — подтвердить (статус → CONFIRMED, вес увеличивается)
   - **Reject** — отклонить (статус → REJECTED, исключается из анализа)
   - **Archive** — архивировать

---

## 5. Свидетельства (Witness Reports)

### 5.1 Добавление свидетельства
1. На панели дела нажать **Witness Reports**
2. Нажать **+**
3. Заполнить:
   - Source name — кто видел (Иван Петров)
   - Source type — тип (phone, in_person, social)
   - Text — описание (Видел пожилую женщину в синем пальто у метро Парк)
   - Location name — место
   - Latitude / Longitude — координаты
   - Confidence — ползунок 0-1
4. Сохранить
5. **Ожидание:** отчёт появился со статусом NEW

### 5.2 Верификация свидетельства
1. Нажать на отчёт
2. Доступные действия:
   - **Verify** — подтвердить (статус → VERIFIED, вес увеличивается)
   - **Reject** — отклонить

---

## 6. Рассылка (Outreach)

### 6.1 Отправка сообщения
1. На панели дела нажать **Outreach**
2. Нажать **+**
3. Заполнить:
   - Channel — канал (TELEGRAM, WHATSAPP, SMS, EMAIL, SOCIAL)
   - Recipient — получатель (Группа поиска в Telegram)
   - Message — текст сообщения
4. Сохранить
5. **Ожидание:** сообщение в списке со статусом SENT

### 6.2 Управление статусами
- **Delivered** — доставлено
- **Read** — прочитано
- **Responded** — получен ответ

---

## 7. Веб-поиск (Web Search)

### 7.1 Поиск в интернете
1. На панели дела нажать **Web Search**
2. **Ожидание:** экран с вкладками:
   - **Text** — текстовый поиск
   - **Images** — поиск по фото
   - **Archives** — архивы Wayback Machine
3. Нажать **Search** (поиск по имени из профиля)

> **Примечание:** Для реального поиска нужен Google CSE API-ключ в `local.properties`. Без ключа будет ошибка или пустой результат.

### 7.2 Продвижение результата в лид
1. В результатах поиска нажать на результат
2. Нажать **Promote to Lead**
3. **Ожидание:** результат сохранён как SearchLead

## 10. Сквозной сценарий (End-to-End)

Полный тест от создания до поиска:

1. Создать профиль с полными данными
2. Добавить 2-3 исторических места
3. Нажать MISSING → заполнить данные → START SEARCH CASE
4. Добавить 2-3 лида с координатами (разные типы: MANUAL, WITNESS, WEB)
5. Подтвердить 1 лид, отклонить 1
6. Добавить 2 свидетельства с координатами
7. Верифицировать 1 свидетельство
8. Открыть Search Map:
   - Проверить маркеры лидов и свидетельств
   - Проверить зоны поиска (фиолетовые круги)
   - Если есть FAB — переключить тепловую карту
9. Отправить 1 сообщение через Outreach
10. Открыть Audit Log — проверить что все действия записаны
11. Вернуться на профиль — проверить что дело активно

## 11. Проверка Signal Engine (ранжирование)

Для проверки обновлённой системы ранжирования:

### Тип лида влияет на вес
1. Добавить лид типа **WITNESS** с confidence 0.8
2. Добавить лид типа **WEB** с confidence 0.8
3. Открыть карту — зона с WITNESS лидом должна быть приоритетнее

### Свежесть увеличивает вес
1. Добавить свежий лид (только что)
2. Добавить старый лид (указать дату вчерашнюю)
3. Открыть карту — свежий лид приоритетнее

### Корреляция источников
1. Добавить в одну точку лид + свидетельство + историческое место
2. В другую точку — 3 лида одного типа
3. Открыть карту — точка с разными источниками должна быть приоритетнее
