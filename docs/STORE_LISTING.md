# SearchAid — Play Store Listing

## App name
SearchAid

## Short description (80 char max)
Coordinate missing-person searches with digital leads and probability-based maps

## Full description (4000 char max)
SearchAid helps families and volunteers launch a structured search for a missing person in minutes — not hours.

Built for the critical first moments after a vulnerable person (Alzheimer's, dementia, elderly) leaves home without a phone, SearchAid combines digital intelligence with field coordination to reduce the time between disappearance and organized search.

HOW IT WORKS

1. Create a person profile with photo, description, known locations, and habits
2. Activate a missing case with last-seen location and clothing details
3. The system automatically builds an identity pack and generates search queries
4. Digital leads are gathered from open web sources, social networks, and public archives
5. A Signal Engine scores and clusters all evidence into probability-based search zones
6. The Search Map shows where to look first — with a heat map overlay for visual priority
7. Field teams mark zones as checked and submit witness reports in real time
8. Zones update dynamically as new information arrives

KEY FEATURES

- Quick case activation — go from "missing" to "searching" in under 2 minutes
- Person profiles with historical places, aliases, and family notes
- Open-source web search (text, images, social profiles, web archives)
- Signal Engine with intelligent ranking: source reliability, time decay, recency boost, and multi-source correlation
- Probability heat map on Google Maps
- Witness report collection with verification workflow
- Search lead management (confirm, reject, archive)
- Full audit log of all actions
- Works offline — all data stored locally with encrypted database
- No account required to start searching

WHO IT'S FOR

- Families of people with Alzheimer's or dementia
- Volunteer search groups
- Care facilities
- Anyone coordinating a search for a missing vulnerable person

PRIVACY & SECURITY

- All data stored locally on device with AES-256 encryption
- No tracking, no ads, no data sold
- Location used only for search coordination
- Open web searches only — no private accounts accessed

SearchAid does not replace emergency services. Always call your local emergency number first.
